# Third-Party Notices

The EzClassify Java SDK is licensed under the Apache License 2.0 (see `LICENSE`). It
redistributes, and depends at runtime on, the third-party components listed
below. Each remains under its own license; the texts referenced here govern your
use of those components.

This file covers **runtime** dependencies only (Maven `compile` and `runtime`
scope). Build- and test-only dependencies (JUnit, JaCoCo, the Maven plugins,
and Gson where it is test-scoped) are not redistributed and are omitted.

To regenerate the resolved list below (CI regenerates it the same way and
fails if this file is stale or a license falls outside the allowlist):

```
./mvnw org.codehaus.mojo:license-maven-plugin:2.7.1:aggregate-add-third-party \
  -Dlicense.excludedScopes=test,provided --batch-mode --no-transfer-progress
node scripts/gen-notices.mjs --write
```

## Gson

The `client` module uses Gson
to parse HTTP responses. Its only declared dependency, the compile-time-only
`error_prone_annotations`, is excluded in the parent POM, so Gson resolves as
a single jar with no runtime dependencies.

- `com.google.code.gson:gson:2.14.0` - **Apache License 2.0**
